## 📌 Sobre o Projeto

Este projeto demonstra a aplicação prática da linguagem **C** e o uso de bibliotecas de terceiros para o processamento de matrizes de dados. Utilizando a biblioteca nativa `libqrencode`, a aplicação converte entradas de texto ou URLs fornecidas pelo usuário em uma matriz gráfica renderizada via caracteres UTF-8 no próprio terminal.

O projeto foi estruturado com foco em boas práticas de software, acompanhado de um `Makefile` para automação do processo de *build* e controle de dependências.

---

## ✨ Recursos

- 🚀 **Geração Instantânea:** Processamento em tempo real de textos e URLs.
- 🎨 **Renderização ASCII/UTF-8:** Exibição nativa no terminal com bordas formatadas.
- ⚙️ **Correção de Erros:** Configurado com o nível `QR_ECLEVEL_L` para balancear tamanho e leitura.
- 🛠️ **Build Automatizado:** Compilação simples através de `Makefile`.
